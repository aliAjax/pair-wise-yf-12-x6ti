# 油站网点台账管理（双台账合并）

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

- **双台账**：巡检端、调度台端各记一份油站信息，每条带改动时间和来源。
- **冲突合并**：两边都动过同一站时——
  - 库存按**盘点时间较新**的算；
  - 营业状态听**现场确认**的；
  - 被压过的一方进**待确认清单**，处置（维持合并值 / 改用对方值）后回写另一侧台账，两边一致才**合成一条**。
- **批次校验**：批内重名、或区域落到东区/西区/机场线之外 → **整批停下**，并说明哪几条没进去。
- **离线**：断网先记本地（待同步）；回网自动合并；同步失败的条目保留原因，可修正后重试；指标和列表全部按合并结果计算。

数据保存在浏览器 localStorage，两个台账、处置记录均持久化。
